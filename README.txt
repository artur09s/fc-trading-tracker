FC Trading Tracker

Private mobile PWA for EA SPORTS FC Ultimate Team trading.

Features:
- Purchases with player, card version, price, quantity, note
- Open investments
- Partial sales
- Automatic 5% EA transaction tax
- Realized profit
- Dashboard and 7-day chart
- History and search
- Starting coin balance
- JSON backup/import
- Offline-capable after installation
- Data stored locally in the browser

IMPORTANT FOR IPHONE:
Safari cannot install this directly from a ZIP/file URL as a reliable PWA. Upload the folder to any static HTTPS host (for example GitHub Pages, Cloudflare Pages, Netlify or Vercel), open the resulting address in Safari, then Share > Add to Home Screen.
No PC needs to stay running after it is hosted.

Data is local to that Safari/PWA installation. Export a backup before deleting browser/site data or changing phones.
